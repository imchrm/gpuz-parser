# CONTEXT.md — goldenpages-scraper

## Назначение проекта

Инструмент для сбора (парсинга) данных о компаниях с сайта
https://www.goldenpages.uz — узбекского бизнес-справочника "Золотые Страницы".

Режим использования: одноразовый дамп по заданным параметрам.
Мониторинг и регулярный запуск не требуются.

Выходной формат: CSV и/или Excel (.xlsx).

---

## Целевой сайт

**URL:** https://www.goldenpages.uz

**Стек сайта:** Классический серверный рендеринг (не SPA/Nuxt).
Сайт работает более 20 лет и построен на традиционной серверной архитектуре
(PHP/Yii судя по CSRF-параметру `_csrf-frontend`). HTML генерируется на сервере
полностью — `requests` + `BeautifulSoup` работают без headless-браузера.

**Языковые версии:**
- Русская (основная): `/rubrics/?Id=N`, `/company/?Id=N`
- Английская: `/en/rubrics/?Id=N`, `/en/company/?Id=N`
- Узбекская: `/uz/rubrics/?Id=N`, `/uz/company/?Id=N`

Для парсинга рекомендуется русская версия как наиболее полная.

**CSRF-токен:** в `<meta name="csrf-token">` на каждой странице. Нужен для
POST-запросов (поиск). Для GET-запросов (страницы компаний, рубрик) не требуется.

---

## Ключевое отличие от yellowpages.uz

Goldenpages.uz использует числовые ID (`?Id=N`) вместо slug-идентификаторов.
Это означает:
- URL компании: `/company/?Id=57473` (не `/company/samarkand-pes`)
- URL рубрики: `/rubrics/?Id=3473` (не `/rubric/restaurants`)
- URL города: `/city/?Id=296` (числовой ID, не текстовый slug)

Числовые ID проще в итерации, но требуют предварительного получения списка
нужных ID перед началом сбора данных.

## Структура URL

### Страница компании
```
https://www.goldenpages.uz/company/?Id={company_id}
```
Пример: `https://www.goldenpages.uz/company/?Id=12988`

### Рубрика (список компаний по категории)
```
https://www.goldenpages.uz/rubrics/?Id={rubric_id}
```
Пример: `https://www.goldenpages.uz/rubrics/?Id=3473`
(Рестораны в Ташкенте, 617 организаций)

На странице отображается: `Найдено организаций: N`

### Город
```
https://www.goldenpages.uz/city/?Id={city_id}
```
Пример: `https://www.goldenpages.uz/city/?Id=296` (Ташкент)
Пример: `https://www.goldenpages.uz/city/?Id=322` (Самарканд, 2343 организации)

### Регион
```
https://www.goldenpages.uz/region/?Id={region_id}
```
Пример: `https://www.goldenpages.uz/region/?Id=333` (Самаркандская область)

### Район (для Ташкента)
```
https://www.goldenpages.uz/district/?Id={district_id}
```
Пример: `https://www.goldenpages.uz/district/?Id=7` (Шайхонтохурский район)

### Расширенный поиск
```
https://www.goldenpages.uz/search/
```
POST-форма с полями: регион, город, район, улица, вид деятельности,
название компании. Точные имена параметров формы требуют проверки при реализации.

### Известные числовые ID городов (частичный список)
| Город     | ID  |
|-----------|-----|
| Ташкент   | 296 |
| Самарканд | 322 |

Полный список ID городов/регионов необходимо получить парсингом главной страницы
или страниц-каталогов.

### Телефоны — критически важная особенность

**В верхней части страницы:** `+998 (71) 227-XX-XX` — номер маскирован,
требует клика JavaScript ("Показать телефон"). Получить через requests нельзя.

**В нижней части страницы (FAQ-блок):** полные номера присутствуют в HTML
в тексте вида:
```
Номер телефона "НАЗВАНИЕ" ООО - 71 2270834; 71 2000056; 1347
```
Несколько номеров разделены точкой с запятой.

Это основной и единственный путь получения телефонов без JavaScript/Selenium.
Стабильность разметки требует проверки на выборке из 10-20 разных компаний.

## Пагинация

**Критически важное наблюдение:** добавление параметра `?page=2` к URL рубрики
(`/rubrics/?Id=3473&page=2`) приводит к перенаправлению на другую рубрику
(ID интерпретируется иначе). Параметр `page` не работает стандартным образом.

Точный механизм пагинации **не установлен** и является blocker-задачей перед
началом реализации. Возможные варианты:
- Кнопка "Показать ещё" (infinite scroll через JS — потребует Selenium)
- Параметр с другим именем (`?p=`, `?offset=`, `?start=`)
- Пагинация полностью через JavaScript (высокий риск)
- Весь список отдаётся на одной странице (маловероятно при 617 записях)

На странице рубрики обнаружена кнопка **"Скачать список"** с иконкой Excel —
это может быть самый быстрый путь получения данных для рубрик с большим
числом компаний. Формат и доступность этого экспорта требуют исследования.

  нужно учитывать при выборе стратегии

## Ограничения и правила работы

- **robots.txt** необходимо проверить вручную перед стартом:
  `https://www.goldenpages.uz/robots.txt`
- Страница поиска (`/search/`) имеет `meta-robots: noindex, nofollow` —
  что может означать ограничения на автоматическый обход.
- Публичный API отсутствует.
- Cloudflare или иная серьёзная AntiBot-защита не обнаружена.
- Сайт крупный (более 20 лет, > 40 000 организаций) — агрессивный парсинг
  недопустим. Обязательны паузы между запросами.
- Сайт использует перенаправление для внешних ссылок через `/go/?u=HASH` —
  прямые URL сайтов компаний из HTML не извлекаются напрямую.
