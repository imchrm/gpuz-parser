# CONTEXT.md — goldenpages-scraper

## Назначение проекта

Инструмент для сбора (парсинга) данных о компаниях с сайта
https://www.goldenpages.uz — узбекского бизнес-справочника "Золотые Страницы".

Режим использования: одноразовый дамп по заданным параметрам.
Мониторинг и регулярный запуск не требуются.

Выходной формат: CSV и/или Excel (.xlsx).

---

## Целевой сайт

**URL:** https://www.goldenpages.uz

**Стек сайта:** Классический серверный рендеринг (не SPA/Nuxt).
Построен на традиционной серверной архитектуре (PHP/Yii, судя по
CSRF-параметру `_csrf-frontend`). HTML генерируется на сервере полностью —
`requests` + `BeautifulSoup` работают без headless-браузера.

**Языковые версии:**
- Русская (основная): `/rubrics/?Id=N`, `/company/?Id=N`
- Английская: `/en/rubrics/?Id=N`, `/en/company/?Id=N`
- Узбекская: `/uz/rubrics/?Id=N`, `/uz/company/?Id=N`

Для парсинга используется русская версия как наиболее полная.

**CSRF-токен:** в `<meta name="csrf-token">` на каждой странице.
Нужен для POST-запросов (поиск). Для GET-запросов (страницы компаний, рубрик)
не требуется.

## Структура URL

### Страница компании
```
https://www.goldenpages.uz/company/?Id={company_id}
```
Пример: `https://www.goldenpages.uz/company/?Id=12988`

### Рубрика (список компаний по категории)
```
https://www.goldenpages.uz/rubrics/?Id={rubric_id}&Page={page}
```
Пример: `https://www.goldenpages.uz/rubrics/?Id=3473` (Рестораны в Ташкенте)

Параметр пагинации — `Page` с заглавной буквы (подтверждено через `Clean-param`
в robots.txt). `page` (строчная) не работает.

### Город
```
https://www.goldenpages.uz/city/?Id={city_id}
```
Пример: `https://www.goldenpages.uz/city/?Id=296` (Ташкент)

### Регион
```
https://www.goldenpages.uz/region/?Id={region_id}
```
Пример: `https://www.goldenpages.uz/region/?Id=333` (Самаркандская область)

### Район
```
https://www.goldenpages.uz/district/?Id={district_id}
```
Пример: `https://www.goldenpages.uz/district/?Id=7` (Шайхонтохурский район, Ташкент)

### AJAX-эндпоинт телефонов
```
GET https://www.goldenpages.uz/scripts/company_data/?cid={company_id}&ctype=phone&clang=ru
```
Открытый эндпоинт, авторизация не нужна. Возвращает HTML-фрагмент.

### Поля и источники в HTML

| Поле                    | Источник в HTML                                   | Примечание                                    |
|-------------------------|---------------------------------------------------|-----------------------------------------------|
| Название                | `<h1>`                                            | Содержит город в скобках — парсер удаляет     |
| Альтернативные названия | `<div class="gp_name_legal">` (сиблинг после h1) | Через `;`                                     |
| ИНН                     | Текстовый узел `"ИНН:"`, значение в родителе/предке | Частично маскируется (`30686****`)           |
| Адрес (город)           | `<a href="/city/?Id=N">`                          |                                               |
| Адрес (район)           | `<a href="/district/?Id=N">`                      |                                               |
| Адрес (улица)           | `<a href="/street/?Id=N">`                        |                                               |
| Адрес (дом)             | Текстовый узел сразу после тега улицы             | Начинается с `, ` — обрезается               |
| Почтовый индекс         | `<a href="/orgbyindex/?Id=N">`                    | Встречается не у всех компаний                |
| Регион                  | `<a href="/region/?Id=N">`                        | Встречается не у всех компаний                |
| Ориентиры               | Текстовый узел `"Ориентиры:"`, через `;`          |                                               |
| Сайт                    | `<a href="/go/?u=HASH" title="Перейти на сайт">`  | URL — в **тексте** ссылки (не в href)         |
| Telegram                | `<a href="/go/?u=HASH" title="Telegram">`         | Текст пустой (SVG-иконка) — сохраняется редирект |
| Виды деятельности       | `<a href="/rubrics/?Id=N">` (только относительные URL) | Абсолютные URL — навигация, не рубрики   |
| Режим работы            | `<div class="gp_work_wrap">` в `<div class="gp_work_time">` | Строка с `fw-600` — заголовок, пропускать |
| Рейтинг (числовой)      | `<div class="review_all__count fw-600">`          | Значение типа `2.33`                          |
| Оценки/отзывы           | `<span>оценок: N | отзывов: N</span>`             | `оценок` — итоговый показатель для поля       |
| Дата обновления         | Текстовый узел `"Обновлено: дд.мм.гггг"`          |                                               |
| Лет на сайте            | Текстовый узел `"N лет/год/года на сайте"`        | Все три формы слова встречаются               |

### Телефоны

Кнопка "Показать телефон" инициирует GET-запрос:
```
GET /scripts/company_data/?cid={company_id}&ctype=phone&clang=ru
```

Ответ — HTML-фрагмент вида:
```html
<ul class="gp_phoneCom someclass">
  <li><a href="tel:+998712270834">+998 71 227-08-34</a></li>
  <li><a href="tel:+998712000056">+998 71 200-00-56</a></li>
  <li><a href="tel:1347">1347</a></li>
</ul>
```

Номер берётся из атрибута `href` (после `tel:`). Форматирование в тексте ссылки
игнорируется — `href` содержит чистый номер.

### Рабочие часы — структура HTML

Рабочие часы НЕ в `<table>/<tr>` — используются `div`-ы:

```html
<div class="gp_work_time collapse">
  <div class="row gp_work_wrap fw-600"><!-- заголовок: День | Время работы | Обед --></div>
  <div class="row gp_work_wrap">
    <div>Пн:</div>
    <div>09.00 - 18.00</div>
    <div>не указан</div>
  </div>
  <div class="row gp_work_wrap gp_time_act"><!-- текущий день: +<div>Сегодня</div> --></div>
  <div class="row gp_work_wrap">
    <div>Сб:</div>
    <div>выходной</div>
    <div>-</div>
  </div>
</div>
```

Время в формате `09.00` (точка вместо двоеточия), парсер нормализует к `09:00`.

### Внешние ссылки

Все внешние ссылки (сайт компании, соцсети, Telegram) скрыты за редиректом
`/go/?u=HASH`. Тип определяется по атрибуту `title`:

| `title`            | Что это         | Где URL?                         |
|--------------------|-----------------|----------------------------------|
| `Перейти на сайт`  | Сайт компании   | В тексте ссылки (`link.get_text()`) |
| `Telegram`         | Telegram-канал  | Текст пустой — URL неизвестен, сохраняется `/go/` редирект |
| `None`             | Навигация сайта | Игнорировать                     |

## Пагинация

**Подтверждено:** серверная пагинация, параметр `Page` (с заглавной буквы).

Из robots.txt:
```
Clean-param: city&region&Page */rubrics/*
```

Страницы: `/rubrics/?Id=3473&Page=2`, `/rubrics/?Id=3473&Page=3`, и т.д.

`page` (строчная) — не работает (перенаправляет на другой ресурс).

Кнопка "Следующая" в пагинации содержит прямую ссылку на следующую страницу —
`listing_parser.get_next_page_url()` ищет её в первую очередь.

## robots.txt — ключевые правила

- `Allow: /rubrics/` — можно парсить рубрики ✅
- `Allow: /company/` — можно парсить страницы компаний ✅
- `Allow: /city/` — можно парсить города ✅
- `Disallow: */search/*` — keyword-поиск запрещён ⛔

## Ограничения и правила работы

- Агрессивный парсинг недопустим — обязательны паузы между запросами (1.5–3.5 сек).
- `/search/*` заблокирован в robots.txt — `keyword_collector` не использовать.
- ИНН на сайте частично маскируется (`30686****`) — полное значение недоступно.
- Telegram-ссылки не содержат читаемого URL (только SVG-иконка).
- Полный текст отзывов ("Показать ещё") недоступен без JS.
- Cloudflare или иная серьёзная AntiBot-защита не обнаружена.
- Сайт крупный (> 40 000 организаций) — сбор займёт значительное время при соблюдении пауз.
